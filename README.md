# Tic-Tac-Toe

A simple two-player game of Tic-Tac-Toe played on a 3×3 grid.

## How to Play

1. Players take turns placing **X** and **O** in an empty square.
2. The first player to place three marks in a horizontal, vertical, or diagonal line wins.
3. If the board fills before either player wins, the game is a draw.

Enjoy the game, and start another round whenever you're ready.
